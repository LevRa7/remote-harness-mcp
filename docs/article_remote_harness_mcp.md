# Gemini Computer Use (Remote Harness MCP): превращаем Google Gemini в полноценного исполнителя на вашем ПК и телефоне

Google Gemini умеет рассуждать, генерировать код и отвечать на сложные вопросы. Но при стандартном использовании в веб-интерфейсе или мобильном приложении у модели нет прямого доступа к вашему окружению: она не может запустить скрипт, просмотреть локальные логи, перезапустить упавший сервис или протестировать изменения в репозитории.

Проект **Remote Harness MCP** (в npm опубликован под именем `gemini-computer-use`) решает эту проблему, используя открытый протокол **Model Context Protocol (MCP)**.

---

## В чем суть проекта?

Вместо того чтобы держать открытые SSH-порты, настраивать сложные VPN или запускать тяжелые веб-клиенты, проект предлагает элегантную архитектуру:

1. **Единая ссылка для подключения:** Сервер подключается к веб-клиенту Gemini или мобильному приложению через Gemini Custom Tools / MCP (SSE / Streamable HTTP).
2. **Безопасный обратный туннель (Reverse WebSocket Tunnel):** Клиентский узел запускается локально на ПК, ноутбуке, VPS или Android (через Termux). Он сам инициирует исходящее защищенное WebSocket-соединение с шлюзом. Никаких открытых входящих портов наружу не требуется.
3. **Строгая модель безопасности и подтверждений (Human-in-the-Loop):**
   - **Безопасные и Read-only операции** (`list_dir`, `read_file`, `grep_search`, `system_info`, `system_vitals`, `mesh_status`) выполняются без лишних диалогов.
   - **Локальные изменения** (`bash_exec`, `write_file`, `edit_file`, `run_job`, `device_control`) отрабатывают быстро и прозрачно в пределах рабочей директории.
   - **Потенциально деструктивные и системные действия** (`system_change`, `system_write`, удаление файлов, `sudo`, пакетные менеджеры) и доступ к сенсорам устройства (`device_capture`, `device_messages`) размечены аннотациями `destructiveHint`. Клиент Gemini Spark перед выполнением обязательно запросит подтверждение у пользователя.

## Архитектура

```text
Gemini App / gemini.google.com (Web)
             │  MCP (SSE / Streamable HTTP)
             ▼
     Gateway  (TLS relay, токен-аутентификация)
             │  исходящий WebSocket-туннель (без открытых портов)
             ▼
   ПК / Ноутбук / VPS / Android Termux  →  локальное выполнение задач
```

## 26 нативных MCP-инструментов

Набор инструментов покрывает полный цикл удаленного администрирования и разработки:
- **Системный мониторинг:** `system_info`, `system_vitals`, `mesh_status`.
- **Работа с терминалом:** `bash_exec` (с поддержкой автоопределения оболочки: PowerShell/CMD на Windows, Bash на Linux/macOS) и фоновый запуск через `run_job`, `job_output`, `job_kill`.
- **Файловая система:** атомарная запись (`write_file`), безопасное редактирование по хэшу (`edit_file`), чтение с пагинацией (`read_file`), поиск (`grep_search`, `glob_find`).
- **Публикация и шаринг:** `share_file`, `serve_dir` для мгновенного развертывания локальных отчетов и файлов в сеть с доступом по одноразовым ссылкам.
- **Управление устройствами (Android/Laptops):** фонарик, громкость, вибрация, TTS, буфер обмена (`device_control`), а также работа с камерой, микрофоном и локацией (`device_capture`).
