# Remote Harness MCP 0.4.6 — device credentials, pairing, and no secret in a URL

Security release. Three changes, all in the gateway; the node's tool surface is
unchanged, and an existing node keeps working.

## The device token is no longer accepted in a URL

`?token=` on `/sse`, `/mcp` and `/messages` used to carry the node's device
token. That token opens the tunnel, and a URL is the worst place to keep it: it
is written to the nginx access log, kept in browser history, forwarded in the
`Referer` header, stored in a third-party client's connector settings and put on
the clipboard by the installer.

Every node now has **two credentials**:

| Credential | Used for | Travels in |
| :--- | :--- | :--- |
| device token | the tunnel and any client that can set a header | `Authorization: Bearer` (or `x-mesh-token`) |
| link key `lk_…` | the MCP URL pasted into Gemini | `?token=` |

A device token presented in a query string is rejected with HTTP 401 and a
message that names the link key. The link key can invoke tools but **cannot open
a tunnel**, so a leaked link cannot be used to impersonate an agent.

Access-log records are scrubbed as well: `token=…` is rewritten to
`token=<redacted>` before anything is written to disk.

## Registrations prove possession, not a MAC address

`/api/register` used to return the token of an **existing** node to any caller
that presented that node's MAC address. A MAC is visible to the whole LAN, is
trivially spoofed, and this was an account takeover with extra steps: the caller
received a token that runs `bash_exec` on someone else's machine.

The reuse-by-MAC branch is gone. Reusing a name now requires that node's device
token in an `Authorization: Bearer` header; without it the gateway answers 409
(or hands out a fresh unique name when `auto_suffix` is set). `mac_address` is
still recorded as inventory, and nothing authenticates with it.

Device tokens are stored as sha256 from now on; the plaintext form is never
written by 0.4.6 and is removed the next time a node proves possession.

## Pairing: `/v1/devices`

The flow that replaces anonymous self-registration:

```bash
# 1. the node asks for a code (10 min TTL, nothing is created yet)
curl -sX POST https://<gateway>/v1/devices/pair \
  -H 'Content-Type: application/json' \
  -d '{"hostname":"workstation","os":"linux","arch":"x64"}'
# → {"pair_code":"K7QM-3XPD","expires_in":600,...}

# 2. a human with admin rights approves it
curl -sX POST https://<gateway>/v1/devices/pair/K7QM-3XPD/approve \
  -H "X-Admin-Token: $MESH_ADMIN_TOKEN" -d '{"username":"workstation"}'

# 3. the node collects its credentials - exactly once
curl -s https://<gateway>/v1/devices/pair/K7QM-3XPD
# → {"status":"approved","username":"workstation","token":"…","link_key":"lk_…","sse_url":"…"}
```

Also new:

- `POST /v1/devices/<node>/rotate` — issue a new link key, kill the old URL
  (admin, or the node's own device token). No reinstall.
- `POST /v1/devices/<node>/revoke` — remove the node and close its tunnel.
- `MESH_REGISTER_MODE=pair` — self-registration returns 410 and pairing becomes
  the only way in. `MESH_ENROLL_SECRET` is the lighter option: keep
  `/api/register` but require a shared secret from the installer.
- `/api/register` is rate limited per IP (10/min); pairing is 20/min.

## Upgrade notes

- Existing nodes keep working: a pre-0.4.6 registry entry with a plaintext token
  still authenticates, and its old URL keeps working until it re-registers or
  rotates. Both paths log a deprecation warning.
- Re-running the installer after this release prints a link-key URL instead of a
  token URL, and stores `MESH_LINK_KEY` next to `MESH_TOKEN` in `agent.env`.
- Agents released before 0.4.6 send their tunnel token in the query string. That
  is still accepted (the tunnel never leaves the host) and logs a warning
  telling the node to update; the agent itself is unchanged.
- Nothing here is a substitute for the paid service's control plane: the
  gateway still has no accounts, and `MESH_ADMIN_TOKEN` is a single operator
  secret, not a multi-tenant authorisation model.
