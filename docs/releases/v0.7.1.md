# Remote Harness MCP v0.7.1 — Faster, leaner MCP surface, shell-free Git & Fetch, OAuth 2.1, and Zero-Admin Standalone Mode

First stable release of the **0.7.x** architecture (no bridge required by default — each node publishes itself via Tailscale Funnel or quick tunnel), combining the fast Windows/Linux data layer, `read_media` multimodal support, GUI installer improvements, and a comprehensive set of context-efficiency, security, and onboarding upgrades.

## Highlights & All Changes Since `v0.7.0-rc1-alpha`

### 1. Context Efficiency & Faster Search
- **~50% smaller `tools/list` schema payload:** compressed tool and parameter descriptions across `core/mcp_tools.py` and `gateway.py` (33 base tools: 33.5 KB → 16.9 KB; default desktop auto-profile of 34 tools: 17.1 KB; `MESH_TOOLSETS=core` of 22 tools: 10.4 KB, **−69%**).
- **Modular toolsets (`MESH_TOOLSETS`) & OS auto-profile:** configure active tool groups (`all`, `core`, `git`, `web`, `device`, `admin`) via `MESH_TOOLSETS`; phone-only tools (`device_messages`, `device_capture`) are hidden by default on desktop nodes unless explicitly enabled. `core/server.py` now serves `tools/list` dynamically via `mcp_tools.list_tools()`.
- **Compact `grep_search` output:** added `format="compact"` returning flat relative paths (`rel/path.py:line: text`), cutting grep response tokens by >50% (13.5 KB vs 30.6 KB), while keeping `format="json"` clean without duplicate fields.
- **Bytes-level literal `grep_search` pre-filter:** `core/fs_search.py` performs a fast `needle_bytes in raw_bytes` check before UTF-8 decoding and regex matching for literal patterns (`fixed=True` or plain literals with `ignore_case=False`).
- **Fast data layer & background indexing:** zero-dependency `fs_search`, SQLite FTS5 `fs_index` with background/scheduled refresh, `win_places`, `doc_read`, `batch_read`, `batch_edit` (with `dry_run`), and multi-language `run_script` (`python`, `powershell`, `bash`, `cmd`).

### 2. New Shell-Free Tools & Multimodal Support
- **`git_status` & `git_diff`:** read-only tools executing `git` directly (`shell=False`, `-c core.fsmonitor=false -c core.hooksPath=`), working even in `read_only` mode or with `--no-shell`.
- **`fetch_url` with SSRF protection:** `https://`-only fetcher validating every resolved IP via `ipaddress` (blocking loopback, private, link-local, multicast, reserved, and IPv4-mapped IPv6), per-hop redirect validation (up to 5 hops), 300 KB body cap, and optional HTML-to-text stripping.
- **`read_media` & binary guard in `read_file`:** `read_file` now detects binary files via NUL-byte check in the first 8 KB and returns a clean error with file size, MIME type, and a hint to use `read_media` (which returns native MCP image/PDF/audio/video/OCR content blocks, plus Windows OCR helper `tools/ocr_windows.py`).

### 3. Security, Reliability & Windows Hardening
- **Protected `.git/` writes:** `core/policies.py` (`is_protected_git_path`, `check_write_allowed`) blocks writes/edits to `.git/hooks/*` and `.git/config` across `write_file`, `edit_file`, and `batch_edit` (handling path traversal, symlinks, Windows case-insensitivity, and NTFS ADS).
- **Shell disable switch (`--no-shell` / `MESH_ENABLE_SHELL=0`):** cleanly disables `bash_exec`, `run_script`, and `run_job` for file-only deployments.
- **No duplicate port bind on Windows:** `core/server.py` disables `allow_reuse_address` and sets `socket.SO_EXCLUSIVEADDRUSE` on `win32`.
- **Async rotating usage journal:** `core/usage.py` writes call logs through a background `queue.SimpleQueue` daemon thread with size-based rotation (1 MB × 3 backups) and `flush()`, cutting empty-call protocol overhead from ~16 ms to ~1 ms.

### 4. Onboarding, OAuth 2.1, Installer & Docs
- **Zero-admin single-folder mode (`--folder`, `--no-shell`, `--quick-tunnel`):** launch a standalone sandboxed server on any project folder without admin privileges or Tailscale setup, with optional Cloudflare quick tunnel (`cloudflared`) auto-detection.
- **Minimal OAuth 2.1 (PKCE S256) in standalone mode:** added `GET /.well-known/oauth-authorization-server`, `GET /.well-known/oauth-protected-resource`, `POST /oauth/register`, `GET /oauth/authorize`, and `POST /oauth/token` alongside static `MESH_TOKEN`.
- **Installer & `rhm` menu updates:** selectable install location and component toggles in `install-gui.ps1`, localised drive labels, tunnel visibility and repair from `rhm`, and updated admin service / container docs.
- **Threat Model & README sync:** added **Threat Model / Модель угроз** sections to `README.md` and `README_RU.md`, updated tool counts (36 node / 38 gateway), and added CI contract test `tests/test_readme_tools_sync.py`.
- **Cross-platform CI fix:** fixed POSIX case-sensitive glob assertions in `tests/test_fs_index.py` so `ubuntu-latest` (py3.11, py3.13) and `windows-latest` (py3.13) all pass cleanly.

## Upgrade / Install

- **curl (Linux / macOS / Termux):**
  ```bash
  curl -fsSL https://raw.githubusercontent.com/LevRa7/remote-harness-mcp/main/install.sh | bash
  ```
- **PowerShell (Windows):**
  ```powershell
  irm https://raw.githubusercontent.com/LevRa7/remote-harness-mcp/main/install.ps1 | iex
  ```
- **npx:**
  ```bash
  npx remote-harness-mcp@0.7.1
  ```
- **Existing nodes:** run `mesh_update` (`action="apply"`) or update from the `rhm` menu — GitHub Releases attaches `mesh-payload-0.7.1.zip`, `RemoteHarnessMCP-Setup-0.7.1.exe`, and their `.sha256` checksums automatically.
